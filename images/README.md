# Image specification

The site loads photos by **exact file name**. Do not rename, move, or change the extension (`.jpg`).

## Banners — `images/banners/<group-id>.jpg`

Tall portrait, about 600x1000 px, JPEG under 250 KB. One dog alone, studio-style, plain solid or soft backdrop (no parks, grass, people, leashes, text). The dog should sit in the lower half; the top half stays empty because the group name is printed there. The page fades it into a colored banner, so a clear, well-lit subject matters most.

| File | Iconic breed |
|---|---|
| `images/banners/sporting.jpg` | Golden Retriever or Labrador Retriever |
| `images/banners/hound.jpg` | Beagle |
| `images/banners/working.jpg` | Doberman Pinscher |
| `images/banners/terrier.jpg` | Scottish Terrier |
| `images/banners/toy.jpg` | Chihuahua or Pomeranian |
| `images/banners/non-sporting.jpg` | Dalmatian or Standard Poodle |
| `images/banners/herding.jpg` | German Shepherd Dog |

## Breeds — `images/breeds/<breed-slug>.jpg`

Landscape 4:3, about 800x600 px, JPEG under 150 KB. One dog of that exact breed, standing or sitting, studio/show-ring style, plain backdrop, whole head and body visible, no text or watermarks. The slug is the breed name lowercased with every run of non-letters/numbers replaced by one `-`.

## Rules

- Verify each image shows the breed named in its row (open it and look). Wrong breed is worse than a missing file; leave a file out if unsure.
- Use only images you are allowed to reuse (Unsplash, Pexels, Pixabay, or Wikimedia Commons CC0/CC-BY/public domain). Record each in `images/CREDITS.md` (file, source URL, author, license).
- No two groups should show the same dog.
- Run `python3 scripts/check_images.py` to list missing files, then commit to `main`.
